Help and backup

1. How JS30 works

JS30 runs real JavaScript inside your browser — no installation, no account. Use a recent Chrome, Edge, Firefox or Safari, on a computer or a phone. A computer with a keyboard is best for typing code.

2. Using the code editors

  • ▶ Run (or Ctrl+Enter) runs your code. What you show with console.log() appears under the editor.
  • ✓ Check tests your solution automatically and shows what is different.
  • Visualize runs the code one step at a time and shows every variable in its box.
  • Programs that use prompt() read their answers from the Input box under the editor: one line for each prompt().
  • Web pages (Week 4) show a live preview of your page next to its console.
  • Reset brings back the original code. A loop that never ends is stopped automatically.

3. Points and levels

You earn points for every quick check you get right the first time, every problem you solve (🌱 10, ⭐ 15, 🔥 25), puzzles, quizzes, review cards you know, and every day you complete (30). Points raise your level. They are just for fun — the real prize is what you can build.

4. Your progress

Your name, points, solved problems, code and notes are saved in this browser on this device. If you clear browser data or change device, they are gone — so download a backup from time to time, and restore it on the new device.

5. After JS30

To write JavaScript on your own computer, install the free editor VS Code, create a file index.html, and open it in your browser. Press F12 in Chrome or Edge to open the real console. Online playgrounds like RunJS work too.
